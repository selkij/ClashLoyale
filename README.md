# ClashLoyale
Pygame copy of clash royale for an NSI project.

> /!\ Will not work with Python 3.14 /!\
## Installation

requirement : 
- python 3.13
- pip
- pygame

Command : 
```bash
  pip install -r requirement.txt # Install all dependencies
  cd src
  python3 main.py
```
