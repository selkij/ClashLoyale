# ClashLoyale
Pygame copy of clash royale but bad, for an NSI project.

> /!\ Will not work with Python 3.14 /!\
## Installation

requirement : 
- python 3.12
- pip

Command
```bash
  pip install -r requirement.txt
  cd src
  python3 main.py
```
